# Data Access and Responsible Use

AWID3 is maintained by the University of the Aegean AWID project. This repository does not redistribute the dataset, packet captures, TLS material, device addresses, or third-party research papers.

Use only an authorized copy obtained through the official access workflow. Store raw captures outside Git, preserve provider documentation, and review local policy before processing packet-level data. Even research captures can contain identifiers or payload material that should not appear in a public repository.

Before publishing derived files:

- Remove MAC addresses, IP addresses, credentials, tokens, and payload content.
- Publish aggregate metrics rather than packet-level records.
- Record the transformation that produced each public artifact.
- Confirm that the dataset terms permit the intended use and redistribution.
- Keep offensive Wi-Fi experiments inside an owned, isolated, and authorized lab.
